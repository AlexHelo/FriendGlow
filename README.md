# FriendGlow

**Spot your people in a crowd.** In World of Warcraft: Forever, FriendGlow gives your party members, friends and guildmates a **green name** and a **green triangle** over their head. You can find them instantly in a packed city or a busy quest area.

It works out of the box: install it, group up, done.

## Features
- **Party and raid members** are highlighted automatically, with no setup.
- **Friends:** your in-game friends list and Battle.net friends playing Forever.
- **Guildmates** (optional).
- **Your own list:** target anyone and type `/fglow add`.
- **Works with Blizzard nameplates and Plater.**
- **Settings page:** *Options → AddOns → FriendGlow*, or type `/fglow`.
- **Keep friendly nameplates on automatically** (optional). FriendGlow draws on nameplates, so it can switch friendly nameplates back on for you after combat, loading screens or a stray key press.
- Lightweight: one file, no libraries.

## Commands
| Command | What it does |
|---|---|
| `/fglow` | Open the settings page |
| `/fglow add <Name>` | Always highlight this player. With no name, it adds your target |
| `/fglow remove <Name>` | Remove someone from your list |
| `/fglow list` | Show your list and current settings |
| `/fglow party` / `friends` / `guild` / `icon` / `plates` | Toggle each option |
| `/fglow test` | Check whether your target counts as a friend, and which nameplates are in use |

## Good to know
- **Friendly nameplates must be on.** WoW gives addons no other way to draw over a player. Turn them on with your friendly-nameplate key, or tick *Keep friendly nameplates on automatically*.
- **Not inside dungeons and raids.** Forever locks friendly nameplates there, so FriendGlow works in the open world, cities and battlegrounds.
- **Plater users:** if guildless players already look green to you, that's Plater's own *guild color* option. Untick it in Plater's friendly-player settings and FriendGlow's green becomes the only one.

## Install
- **CurseForge app:** search for "FriendGlow" with the game set to **WoW Forever**.
- **Manual:** download the zip and extract it so the `FriendGlow` folder sits in `World of Warcraft\_forever_\Interface\AddOns\`.
